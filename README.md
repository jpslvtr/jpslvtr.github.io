# jpslvtr.github.io

Personal website, served at [jpslvtr.com](https://jpslvtr.com).

A static site with no build step: plain HTML, CSS, and a little JavaScript.

## Structure

- `index.html` home page
- `writing.html` writing index
- `p/` individual posts and list pages
- `style.css` all styles
- `theme.js` light/dark theme toggle
- `img/` images and book covers

## Deploy

Hosted on GitHub Pages; pushing to `main` publishes the site.
Run `./deploy.sh` to commit and push.
